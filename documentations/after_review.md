# ТЗ: Этап 5.1. План правок UI/UX, перезапуска заезда и валидации кнопок

**Проект:** «Терра-Хоппер Онлайн» (Django + HTMX)

**Цель:** Устранить баги с однократным выполнением действий, убрать лишнее управление из Гаража, настроить сброс дистанции при старте заезда, увеличить карту и реализовать динамическую блокировку недопустимых кнопок.

---

## 1. Изменения в Гараже (Dashboard)

1. **Удаление кнопок действий с карточки в Гараже:**
   * Полностью убрать кнопки перемещений (`Прыжок`, `Дальний прыжок`, `Форсаж`, `Под землю` и т.д.) из карточки транспорта в Гараже.
   * На карточке транспорта в Гараже должна остаться **только одна управляющая кнопка — «Запустить заезд»**.

2. **Старт заезда с 0 метров:**
   * При нажатии кнопки **«Запустить заезд»** (переход на `/hopper/<id>/game/`) сбрасывать текущие показатели сессии:
     * `distance = 0.0`
     * `strength = 100.0`
     * `reactor_energy = 100.0`
     * `location_state = "surface"`
   * **Важно:** Поле `best_distance` (рекорд) НЕ сбрасывается и сохраняется в БД!

## 2. Доработка игрового экрана и 2D-карты

1. **Размер и пропорции трека (Карты):**
   * Увеличить общий размер блока карты (сделать его крупнее по высоте и ширине).
   * Зоны **«ПОВЕРХНОСТЬ»** и **«ПОДЗЕМЕЛЬЕ»** сделать строго **равными по высоте (50% / 50%)**.

2. **Бесконечный / Многократный игровой цикл (Исправление бага с 1 действием):**
   * Исправить баг, из-за которого после первого действия интерфейс переставал реагировать.
   * Пользователь должен иметь возможность совершать цепочку из 5–10+ действий подряд без необходимости выходить в Гараж, пока не закончится сила/энергия или пока он сам не решит вернуться.
   * HTMX должен корректно обновлять карточку состояния, карту и доступность кнопок при каждом клике.

## 3. Динамическая блокировка кнопок (Disabled States)

На основе текущего состояния транспорта (`location_state`, `strength`, `reactor_energy`) кнопки управления должны **автоматически становиться неактивными (`disabled`)**, если условие для выполнения не соблюдено:

### Правила доступности кнопок:

1. **`Обычный прыжок (+10м)`**:
   * `disabled`, если `location_state == "underground"`
   * `disabled`, если `strength < (3.0 + mass_kg / 100.0)`

2. **`Дальний прыжок (+30м)`**:
   * `disabled`, если `location_state == "underground"`
   * `disabled`, если `strength < (10.0 + (mass_kg / 100.0) * 2.0)`

3. **`Форсаж реактора (+45м)`**:
   * `disabled`, если `location_state == "underground"`
   * `disabled`, если `strength < (10.0 + (mass_kg / 100.0) * 2.0)`
   * `disabled`, если `reactor_energy < 50.0`

4. **`Погружение под землю`**:
   * `disabled`, если `location_state == "underground"` (уже под землей)
   * `disabled`, если `strength < (3.0 * (mass_kg / 100.0))`

5. **`Выйти на поверхность`**:
   * `disabled`, если `location_state == "surface"` (уже на поверхности)
   * `disabled`, если `strength < (3.0 * (mass_kg / 100.0))`

6. **`Подземное бурение (+40м)`**:
   * `disabled`, если `location_state == "surface"`
   * `disabled`, если `strength < (10.0 + (mass_kg / 100.0) * 3.0)`
   * `disabled`, если `reactor_energy < 50.0`

> **Визуализация:** Неактивные кнопки становятся полупрозрачными (`opacity: 0.5`, `cursor: not-allowed`).
