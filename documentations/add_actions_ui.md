# ТЗ: Этап 5. Игровой экран (Интерактивная карта, анимация движения и управление)

**Проект:** «Терра-Хоппер Онлайн» (Django + HTMX)

**Фокус этапа:** Запуск игры из карточки транспорта, переход на игровой экран с интерактивной 2D-картой, визуализацией состояния (поверхность/подземелье), кнопками действий и анимированным продвижением транспорта (прямоугольника).

---

## 1. UX/UI и пользовательский сценарий

1. **Запуск из Гаража (Dashboard):**
   * На каждой карточке транспорта в гараже появляется кнопка **«Запустить заезд»**.
   * При клике происходит переход на игровой экран: `/hopper/<id>/game/`.

2. **Игровой экран (`/hopper/<id>/game/`):**
   * **Верхняя панель (Хедер):** Кнопка «← Назад в гараж», Имя транспорта, Текущая дистанция, Рекорд (`best_distance`).
   * **Интерактивная 2D-карта (Холст/Трек):**
     * Графическое разделение на две зоны по высоте: **Поверхность (небо/земля)** и **Подземелье (грунт)**.
     * Транспорт отображается в виде **прямоугольника (блока)** с именем крота.
     * По горизонтали X отображается продвижение вперед по трассе в зависимости от `distance`.
     * По вертикали Y положение блока меняется при вызове `go_underground` (спуск под землю) и `return_to_surface` (подъем на поверхность).
   * **Панель статусов (Шкалы):**
     * Прогресс-бары для `strength` (Сила) и `reactor_energy` (Энергия реактора).
     * Индикатор текущего положения (`surface` / `underground`).
   * **Панель управления (Кнопки действий):**
     * `Обычный прыжок (+10м)`
     * `Дальний прыжок (+30м)`
     * `Форсаж реактора (+45м)`
     * `Погружение под землю` / `Выйти на поверхность` (зависит от текущего `location_state`)
     * `Подземное бурение (+40м)`
   * **Блок всплывающих сообщений / Ошибок (Toast Alert):**
     * Место для вывода сообщений из доменных исключений (например, *«Недостаточно энергии реактора для форсажа»*).

## 2. Архитектура и маршруты

### 2.1. Новые маршруты (`apps/hopper/urls.py`)

```python
from django.urls import path
from . import views

app_name = "hopper"

urlpatterns = [
    # ... предыдущие урлы
    path("<int:hopper_id>/game/", views.hopper_game_view, name="game"),
    path("<int:hopper_id>/state/", views.hopper_state_api_view, name="state_api"),
]
```

### 2.2. Представления (`apps/hopper/views.py`)

1. **`hopper_game_view` (GET):**
   * Отображает полную страницу игры `templates/hopper/game.html` для указанного `hopper_id`.

2. **`hopper_action_view` (POST, обновлено):**
   * Принимает команды управления. При HTMX-запросе возвращает обновившуюся панель состояния и отправляет заголовок `HX-Trigger` со свежими данными для JS-анимации карты.

## 3. Интерактивная 2D-карта (Canvas / CSS Grid)

Визуализацию карты можно реализовать с помощью HTML5 `<canvas>` или комбинации CSS/JS.

### 3.1. Структура карты
* **Ширина трека:** Карта отображает отрезок трассы (например, окно в 100 метров или зацикленный скролл с метками 0m, 50m, 100m, 200m).
* **Горизонтальное перемещение (X):** При увеличении `distance` прямоугольник плавно сдвигается вправо с помощью CSS `transition: transform 0.4s ease-in-out` или Canvas `requestAnimationFrame`.
* **Вертикальное перемещение (Y):**
  * При `location_state == "surface"`: Y = 30% высоты карты (на уровне земли).
  * При `location_state == "underground"`: Y = 75% высоты карты (в толще грунта).

```
+-------------------------------------------------------------+
|  [ПОВЕРХНОСТЬ]                                              |
|                   +-------------+                           |
|                   |  КРОТ-1     |                           |
|  -----------------+-------------+-------------------------  | (Уровень земли)
|  [ПОДЗЕМЕЛЬЕ]                                               |
|                                                             |
+-------------------------------------------------------------+
```

## 4. Поведение HTMX и JavaScript-синхронизация

1. **Отправка команд:**
   * Каждая кнопка на панели управления использует HTMX для отправки POST-запроса на `/hopper/<id>/action/`.
   * Во время выполнения запроса кнопки временно блокируются (`disabled`), защищая от спама кликами.

2. **Обновление состояния UI:**
   * Сервер возвращает фрагмент с актуальными значениями `strength`, `reactor_energy`, `distance`, `location_state`.

3. **Обработка ошибок (Доменные исключения):**
   * При статусе `400 Bad Request` HTMX заменяет содержимое блока `#game-toast` на текст ошибки (красное всплывающее уведомление, исчезающее через 3 секунды).

4. **Анимация транспорта на карте:**
   * Бэкенд передает новые координаты через JSON/HTMX event (`HX-Trigger: updateMap`).
   * Небольшой скрипт на странице подхватывает событие и анимирует плавающий прямоугольник на карте:

```javascript
document.body.addEventListener("updateMap", function(evt) {
    const data = evt.detail;
    const hopperElement = document.getElementById("hopper-block");
    
    // Вычисление смещения по X и Y
    const posX = (data.distance % 200) * 3; // Масштабирование по горизонтали
    const posY = data.location_state === "underground" ? 180 : 40;
    
    hopperElement.style.transform = `translate(${posX}px, ${posY}px)`;
});
```
